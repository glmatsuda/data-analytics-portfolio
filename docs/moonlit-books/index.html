How the concierge works
Question→BM25 retrieval→Local Qwen3→Contract + handoff rules→Answer + sources

Record IDs are constrained to retrieved evidence and checked again after generation. Recognized missing-title requests trigger a full cached-catalog lookup and an application-owned human-review requirement. This is a workflow control, not proof that every model sentence is correct.

What changed after a failing test?
The previous Open Library run passed 17/18. The assistant recognized a missing title but failed to set the expected human-handoff flag. The corrected pipeline checks recognized titles against the cached catalog, constrains the model output, and independently enforces human review. Original failures are retained in the repository. The latest 18/18 result measures this combined workflow, not an unassisted model.
